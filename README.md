# Tatheer Fatima | Front-End Portfolio

A personal portfolio website showcasing my skills, projects, education, certifications, and practical experience in front-end development and computer science.

## Project Overview

This portfolio was developed as a front-end development project during my internship work at EXPS Nexus.

The website presents my technical skills, academic background, certifications, projects, and development experience through a responsive single-page interface.

## Features

- Responsive single-page portfolio
- About Me section
- Technical Skills section with technology logos
- Project Details section
- Internship Experience section
- Education section
- Certifications section
- Recommendations section
- Contact section
- GitHub and LinkedIn links
- View and Download Resume options
- Light and Dark mode
- Smooth navigation between sections
- Interactive recommendation submission
- Home button for returning to the top of the page
